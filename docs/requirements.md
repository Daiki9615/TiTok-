## 1. 目的

TikTok の**アフィリエイト系動画**の URL をまとめて貼ると、各動画を最初から最後まで文字起こしして保存し、
「売れている動画はどんな言葉・構成で話しているか」の傾向を分析できるツールを作る。

## 2. 前提（確定事項）

| 項目 | 決定内容 |
|---|---|
| 利用者 | 本人のみ |
| 画面 | ブラウザで操作 |
| 費用 | 無料で運用 |
| 対象言語 | 日本語のみ |
| 文字起こし範囲 | **動画 1 本を最初から最後まで全部**（途中で切らない） |
| 字幕の扱い | 字幕があっても使わず、必ず音声から文字起こし |
| AI（LLM）機能 | 使わない |
| 動画の集め方 | URL をまとめて貼る（改行区切り） |
| 分析の本数 | 1 回の分析は最低 10 本 |
| データの置き場所 | **Mac ではなくネット上**（Mac の容量に余裕がないため） |
| 使う PC | 2020 年頃の MacBook Pro（チップの種類は未確認 → Q13） |

## 3. スコープ

### 3.1 対象
- 公開されている TikTok 動画（短縮 URL を含む）
- 文字起こし結果と動画情報をネット上に保存
- アフィリエイト動画に特化した分析

### 3.2 対象外
- 非公開動画・LIVE、LLM による要約、テロップの読み取り（OCR）、話者の区別、日本語以外

## 4. 機能要件

### 4.1 文字起こし

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-01 | URL 一括入力 | 複数の URL を改行区切りで貼り付け。不正な URL・重複はスキップして報告 | 必須 |
| F-02 | 短縮 URL 解決 | 短縮 URL を元の URL に変換 | 必須 |
| F-03 | 音声取得 | 音声を一時的に取得し、処理後に削除 | 必須 |
| F-04 | 全編文字起こし | 動画の最初から最後まで文字起こし | 必須 |
| F-05 | タイムスタンプ | 発言ごとに「何秒目か」を保存（冒頭・締めの分析に使う） | 必須 |
| F-06 | 進捗表示 | 「3/10 本目 文字起こし中」のように表示。失敗した動画は理由を表示し、残りは続行 | 必須 |
| F-07 | 結果表示・コピー | 1 本ごとの全文表示とコピー | 必須 |
| F-08 | 書き出し | txt / csv（SRT は任意） | 推奨 |

### 4.2 データ保存（ネット上）

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| D-01 | 保存 | 文字起こし（全文・タイムスタンプ付き）を保存 | 必須 |
| D-02 | 動画情報 | URL、投稿者、投稿日、キャプション、ハッシュタグ、長さ、再生数・いいね数・コメント数・保存数（取得できる範囲。取得時点の値） | 必須 |
| D-03 | 一覧・検索 | 保存済み動画の一覧、キーワード検索 | 必須 |
| D-04 | 重複防止 | 同じ動画は再処理しない | 推奨 |
| D-05 | 自分用ラベル | ジャンル（美容・ガジェット等）、商品名、案件名などを手入力 | 推奨 |

### 4.3 分析（アフィリエイト動画向け）

対象: 絞り込んだ 10 本以上の動画

| ID | 分析 | 内容 | 優先度 |
|---|---|---|---|
| A-01 | 頻出語ランキング | よく使われる単語の上位（「です」等は除外） | 必須 |
| A-02 | 冒頭の言葉（つかみ） | 最初の 3 秒・5 秒で何を言っているかを一覧化し、よく使われる言い回しを集計（例:「これ買ってよかった」「〇〇な人見て」） | 必須 |
| A-03 | 誘導の言葉（行動の呼びかけ） | 「プロフのリンク」「概要欄」「カゴ」「クーポン」「今だけ」「セール」などが出るか、何秒目に出るか | 必須 |
| A-04 | 訴求の言葉 | 悩み・ベネフィット・価格系の表現（「〜円」「〇% OFF」「コスパ」「神」等）の出現回数。辞書は自分で追加・編集できる | 必須 |
| A-05 | PR 表記の有無 | 発話・キャプションに「PR」「広告」「プロモーション」等があるか | 推奨 |
| A-06 | 数値との関係 | ある言葉を含む動画と含まない動画で、再生数・いいね数の平均を比較 | 推奨 |
| A-07 | 比較 | 投稿者別・ジャンル別・再生数上位と下位などで A-01〜A-04 を並べて比較 | 推奨 |
| A-08 | 話す速さ | 動画 1 本の総文字数 ÷ 動画の長さ で「1 分あたり何文字のペースで話しているか」を計算（文字起こし自体は全編行う。これは速さの指標） | 任意 |
| A-09 | 動画の長さと数値 | 動画の長さと再生数の関係 | 任意 |
| A-10 | 書き出し | 分析結果を csv で保存 | 推奨 |

### 4.4 処理の流れ

```
URLをまとめて貼る
 → URL確認・重複チェック
 → 1本ずつ：動画情報＋音声取得 → 全編文字起こし → ネット上に保存 → 音声削除
 → 一覧画面で確認
 → 分析画面で絞り込み（10本以上）→ 集計・グラフ
```

## 5. 非機能要件

| 区分 | 要件（目標値は仮） |
|---|---|
| 性能 | 10 本（各 1 分程度）を 15 分以内に処理（実行場所で大きく変わる。試作で計測） |
| 精度 | 商品名・ブランド名は誤認識しやすいため、辞書登録や手修正ができること |
| Mac の容量 | Mac に保存するのはできるだけゼロに近づける |
| データ量 | 文字起こしはテキストのみなので、1,000 本でも数 MB 程度の見込み（推測） |
| 費用 | 無料 |
| 保守 | 動画取得部分を分けて作り、yt-dlp を定期更新 |
| 取得間隔 | 一括処理では 1 本ごとに数秒あける |

## 6. 実行場所・保存場所の案（Q14 で決定）

文字起こしの処理には、ソフトと音声認識モデルで数 GB の空きが必要な見込み（推測ですが、モデルサイズにより約 0.5〜3GB ＋ ソフト 1〜2GB）。データ（文字起こし）自体はごく小さい。

| 案 | 処理する場所 | 保存場所 | Mac の容量 | 長所 | 短所 |
|---|---|---|---|---|---|
| **A. 全部ネット上** | Google Colab（ブラウザで動く Google の無料 Python 環境） | Google ドライブ / スプレッドシート | ほぼ使わない | Mac に何も入れない。無料の範囲で GPU を使える場合がある | 使うたびにノートを開いて実行する。無料枠には利用制限がある（内容は未確認）。画面はシンプル |
| B. 処理は Mac、データはネット上 | Mac | Google スプレッドシート | 数 GB 必要 | 画面を作り込める。待ち時間が安定 | Mac の空きが必要。Intel Mac だと遅い可能性 |
| C. 無料のネット上サーバーに画面ごと置く | Streamlit Community Cloud 等 | Google スプレッドシート等 | 使わない | URL を開くだけで使える | 無料サーバーは非力で文字起こしが遅い・止まる可能性。TikTok がサーバーからのアクセスを拒否する可能性（推測） |

**推奨: 案 A**（Mac の容量問題を確実に避けられ、無料で GPU を使える可能性がある）。
保存はスプレッドシートにすると、Google スプレッドシート上でもそのまま並べ替え・フィルタできる。

## 7. 技術方針（案 A の場合）

| 役割 | 候補 |
|---|---|
| 実行環境 | Google Colab |
| 動画情報・音声取得 | yt-dlp + ffmpeg |
| 文字起こし | OpenAI Whisper または faster-whisper（Colab の NVIDIA GPU で動く） |
| 日本語の単語分割 | SudachiPy または Janome |
| 保存 | Google スプレッドシート（動画情報・全文）＋ Google ドライブ（タイムスタンプ付き詳細 json） |
| 画面 | Colab のフォーム（URL 入力欄・ボタン）＋ グラフ表示 |

※ 案 B（Mac で処理）になった場合は、Apple シリコンなら mlx-whisper、Intel なら whisper.cpp を候補とする。

## 8. 規約・法律の注意

- TikTok の利用規約は未確認（作業環境から接続できなかった）。推測ですが、外部ツールでの動画取得は規約に反する可能性がある
- 文字起こしの公開・再配布・商用利用は、著作権について専門家（弁護士）に確認が必要
- 他人の動画の言い回しを分析して参考にすることと、そのまま真似して使うことは別。台本の丸写しは著作権上の問題になりうる（専門家に確認が必要）
- 日本では広告であることを隠した宣伝（ステルスマーケティング）が景品表示法で規制されている。推測ですが、A-05 は自分の動画作成時の確認にも使える。正確な内容は消費者庁の一次情報で要確認（作業環境から接続できず未確認）

| 段階 | 内容 | 完了条件 |
|---|---|---|
| 0. 試作 | 実際のアフィリエイト動画 10 本で、取得・全編文字起こしの精度と時間を測る。商品名の誤認識を確認 | 精度・時間の結果表 |
| 1. 文字起こし＋保存 | F-01〜F-08、D-01〜D-02 | URL をまとめて貼るとスプレッドシートに保存される |

| 4. 追加 | A-06〜A-09 | 数値との関係が見られる |

## 用語

- **SRT**: 字幕ファイルの形式。発言ごとに「何秒から何秒か」を付けたテキスト
- **Google Colab**: ブラウザ上で Python を動かせる Google のサービス。自分の PC に何も入れずに使える
- **yt-dlp**: 動画サイトから動画情報・音声を取得する無料ソフト
- **Whisper**: OpenAI が無料公開している音声認識モデル
