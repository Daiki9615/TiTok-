## 1. 目的

**中心となる機能は「TikTok 動画の文字起こし＆分析」**。URL を貼ると全編を文字起こしして保存し、1 本からでも話し方・構成の傾向を分析できる。

その上に、目的別の**追加モード**を用意する。

| モード | 対象 | 追加される機能 |
|---|---|---|
| 基本（全員） | すべての動画 | 文字起こし・保存・閲覧・共通分析・構成の骨組み作成 |
| 店舗 SNS モード | お店の SNS 担当 | 店舗向け分析（来店誘導・特典）、店舗情報の記入、店舗向け構成作成 |

## 2. 前提（確定事項）

| 項目 | 決定内容 |
|---|---|
| 利用者 | 本人のみ |
| 使う PC | 2020 年頃の MacBook Pro（Intel）。容量に余裕なし |
| 実行場所 | **Google Colab**（Mac には何も入れない） |
| 保存場所 | **Google ドライブ / スプレッドシート**。ただし閲覧は**ツールの画面上**で行える |
| 費用 | 無料 |
| 対象言語 | 日本語のみ |
| 文字起こし | 全編。字幕があっても常に音声から |
| 動画の集め方 | URL をまとめて貼る |
| 分析の本数 | **1 本から**分析可能（複数本ならまとめて集計・比較） |
| 対象ジャンル | **一般**（どんな動画でも）／**店舗 SNS**（お店の集客に使える動画） |
| アフィリエイト機能 | **作らない**（v1.2 で削除） |
| 構成作成 | ツールは骨組み＋ Claude に渡す依頼文まで作る。台本は Claude で作る |

## 3. スコープ

### 3.1 対象
- 公開 TikTok 動画の文字起こし・保存・閲覧
- 1 本以上の動画の分析（動画の種類ごとに分析項目を切り替え）
- 分析結果をもとにした動画構成案の作成（店舗 SNS 用は店舗情報を反映）

### 3.2 対象外
- アフィリエイト向けの機能（案件情報の貼り付け・整理、アフィ向け分析）
- 非公開動画・LIVE、テロップの読み取り、話者の区別、日本語以外
- 動画そのものの編集・作成、TikTok への投稿

## 4. 画面構成

| 画面 | 内容 |
|---|---|
| ① 取り込み | URL をまとめて貼る → 文字起こし・保存。動画の種類（一般 / 店舗 SNS）とラベルを選ぶ |
| ② 一覧・閲覧 | 保存済み動画の一覧、絞り込み、検索、1 本ごとの全文（タイムスタンプ付き）表示、商品名などの手修正 |
| ③ 分析 | 動画を 1 本以上選んで分析。結果を表・グラフで表示 |
| ④ 構成作成 | 「どんな動画にしたいか」を記入（店舗 SNS なら店舗情報も記入）→ 構成案を表示・保存 |
| ⑤ 辞書設定 | 分析で数える言葉の一覧（8 章）の確認・追加・削除 |

画面の作り方（案）: Colab 上で **Gradio**（Python で画面を作る無料ライブラリ）を起動し、表示されるリンクをブラウザで開いて操作する。
推測ですが、このリンクは一時的なもので、Colab を起動するたびに変わる。他人がリンクを知ると開けてしまうため、パスワードをかける。

## 5. 機能要件

### 5.1 取り込み（文字起こし）

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-01 | URL 一括入力 | 改行区切りで複数貼り付け。不正・重複はスキップして報告 | 必須 |
| F-02 | 短縮 URL 解決 | | 必須 |
| F-03 | 動画の種類 | 「一般」「店舗 SNS」を選ぶ（後から変更可） | 必須 |
| F-04 | 全編文字起こし | 一時取得した音声を全編文字起こしし、音声は削除 | 必須 |
| F-05 | タイムスタンプ | 発言ごとに秒数を保存 | 必須 |
| F-06 | 進捗表示 | 「3/10 本目 処理中」。失敗した動画は理由を表示し、残りは続行 | 必須 |

### 5.2 保存・閲覧

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| D-01 | 保存 | 動画情報と全文はスプレッドシート、タイムスタンプ付き詳細は Google ドライブ | 必須 |
| D-02 | 動画情報 | URL、投稿者、投稿日、キャプション、ハッシュタグ、長さ、再生数・いいね数・コメント数・保存数（取得できる範囲・取得時点の値） | 必須 |
| D-03 | ツール上での閲覧 | 一覧・絞り込み・検索・全文表示をツールの画面で行える（スプレッドシートを直接開かなくてよい） | 必須 |
| D-04 | 手修正 | 誤認識した文字（商品名など）を画面上で直して保存 | 必須 |
| D-05 | ラベル | ジャンル・投稿者の種類・商品名など自由なラベル | 推奨 |
| D-06 | 書き出し | txt / csv | 推奨 |

### 5.3 分析（1 本から）

**共通（全ジャンル）**

| ID | 分析 | 1 本のとき | 複数本のとき | 優先度 |
|---|---|---|---|---|
| A-01 | 頻出語 | その動画でよく使う言葉 | 全体の頻出語ランキング | 必須 |
| A-02 | 冒頭のつかみ | 最初の 3 秒・5 秒の発言 | よく使われる言い回しの集計 | 必須 |
| A-03 | 構成の流れ | 時間ごとに何を話しているかを区切って表示（例: 0〜3 秒つかみ / 3〜20 秒本題 / 最後 5 秒締め） | 区切り方の傾向 | 必須 |
| A-04 | 締めの言葉 | 最後の数秒の発言 | 締めの言い回しの集計（「フォローしてね」等） | 必須 |
| A-05 | 話す速さ | 総文字数 ÷ 長さ（1 分あたり文字数） | 平均・ばらつき | 推奨 |
| A-06 | 動画の長さ | 長さ | 長さと再生数の関係 | 推奨 |
| A-07 | 数値との関係 | — | ある言葉を含む/含まない動画の再生数・いいね数比較 | 推奨 |
| A-08 | 比較 | — | 投稿者別・ジャンル別・再生数上位と下位 | 推奨 |

**店舗 SNS 向けの追加分析**

| ID | 分析 | 内容 | 優先度 |
|---|---|---|---|
| SH-01 | 来店誘導の言葉 | 「予約」「DM」「Google マップ」「〇〇駅」「営業時間」等が出るか、何秒目か | 必須 |
| SH-02 | お店の見せ方 | 店名・場所・商品/メニュー・人（スタッフ）・雰囲気のどれを話しているか | 推奨 |
| SH-03 | 特典・限定 | 「この動画見たで」「初回」「限定」等の来店特典の言葉 | 推奨 |

※ SH-01〜SH-03 などで数える言葉は「8. 辞書」で管理。

### 5.4 構成作成

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| C-01 | 参考動画の選択 | 分析した動画（1 本以上）を参考として選ぶ | 必須 |
| C-02 | 作りたい動画の記入欄 | 自由記述（例: 「30 秒で、20 代女性向けに、朝の時短を伝えたい」） | 必須 |
| C-03 | 条件の指定 | 動画の長さ、ジャンル、雰囲気（任意） | 推奨 |
| C-04b | 店舗情報の記入欄 | 店舗 SNS 用のとき表示。店名、業種、場所・最寄り駅、営業時間、看板商品/メニュー、価格帯、来店特典、予約方法 | 必須 |
| C-05 | 構成案（骨組み）の出力 | AI を使わずに作る、時間ごとの構成表（秒数 / パート名 / 入れる要素 / 参考フレーズ / 参考にした動画の該当部分） | 必須 |
| C-05b | Claude 用依頼文の作成 | 骨組み・分析結果の要約・記入内容・店舗情報（店舗 SNS のとき）をまとめた依頼文を作り、ワンクリックでコピー。Claude（claude.ai）に貼ると台本が作れる | 必須 |
| C-07 | 保存・編集 | 構成案を保存し、画面上で手直しできる。txt / csv 書き出し | 必須 |

出力イメージ（30 秒・店舗 SNS の例）:

| 秒数 | パート | 話す内容の案 | 参考 |
|---|---|---|---|
| 0〜3 | つかみ | 「〇〇駅でこのボリュームは反則」 | 参考動画 A の冒頭の型 |
| 3〜12 | 看板メニュー | （店舗情報の看板メニュー・価格帯） | 参考動画 B |
| 12〜22 | お店の雰囲気・人 | 店内・スタッフの紹介 | |
| 22〜27 | 来店特典 | （店舗情報の特典） | |
| 27〜30 | 誘導 | 「場所はプロフから、予約は DM で」 | 上位動画で多い締め |

**構成案の作り方（確定: 方式 Z）**

1. ツールが分析結果から骨組み（上の表）を作る（AI なし・無料）
2. ツールが「Claude 用の依頼文」を作る
3. 依頼文をコピーして claude.ai に貼り、台本を作ってもらう
4. 必要なら完成した台本をツールに貼り付けて保存（C-07）

ツールから Claude を直接呼び出す方式（Claude API）は、利用量に応じた料金と API キーが必要なため、今回は採用しない（将来の追加候補）。

## 6. 非機能要件

| 区分 | 要件（目標値は仮） |
|---|---|
| 性能 | 10 本（各 1 分程度）を 15 分以内に処理（Colab の GPU が使えた場合。試作で計測） |
| Mac の容量 | Mac には何も保存しない |
| 費用 | 無料（Claude は本人がすでに使っている claude.ai を利用） |
| セキュリティ | 画面リンクにパスワード。ツール自身はデータを外部に送らない（Claude に貼るのは本人の操作） |
| 保守 | 動画取得部分を分けて作り、yt-dlp を定期更新 |
| 取得間隔 | 一括処理では 1 本ごとに数秒あける |

## 7. 技術方針

| 役割 | 採用（案） |
|---|---|
| 実行環境 | Google Colab |
| 画面 | Gradio |
| 動画情報・音声取得 | yt-dlp + ffmpeg |
| 文字起こし | faster-whisper（Colab の NVIDIA GPU を利用。GPU が使えないときは CPU で遅くなる） |
| 日本語の単語分割 | SudachiPy または Janome |
| 保存 | Google スプレッドシート＋ Google ドライブ |
| 構成作成 | 骨組みはテンプレート方式。台本は Claude（claude.ai）に依頼文を貼って作る |

## 8. 辞書（Q16 の説明）

分析で「この言葉が何回・何秒目に出たか」を数えるための、**探す言葉の一覧**。
文字起こしの中からこの一覧の言葉を探して数える。自分のジャンルに合わせて言葉を追加・削除できる。

| 分類 | 初期値（例。こちらで用意） |
|---|---|
| 誘導 | プロフのリンク、プロフィール、概要欄、カゴ、ショップ、クーポン、コード、詳細は |
| 期限・限定 | 今だけ、期間限定、セール、本日まで、在庫 |
| お得感 | 円、% オフ、半額、コスパ、無料、送料 |
| 悩み | 悩んでる、困ってる、〜な人、私も |
| 効果・評価 | 神、優勝、リピ、買ってよかった、本当に、マジで |
| 締め | フォロー、保存、いいね、コメント |
| PR | PR、広告、プロモーション、提供 |
| 来店誘導（店舗） | 予約、DM、Google マップ、駅、徒歩、営業時間、定休日、テイクアウト |
| 来店特典（店舗） | この動画見た、初回、限定、サービス、プレゼント |

→ 入れたい言葉が特になければ、この初期値で始めて後から画面で追加する。

## 9. 規約・法律の注意

- TikTok の利用規約は未確認。推測ですが、外部ツールでの動画取得は規約に反する可能性がある
- 文字起こしの公開・再配布・商用利用、および他人の動画の台本をそのまま使うことは著作権上の問題になりうる。専門家（弁護士）に確認が必要。構成作成は「型」を参考にする用途とし、文言の丸写しを避ける
- 店舗の宣伝を他人（インフルエンサー等）に依頼して投稿してもらう場合、景品表示法のステルスマーケティング規制（広告であることの表示）の対象になりうる。正確な要件は消費者庁の一次情報で要確認（未確認）

## 用語

- **Google Colab**: ブラウザで Python を動かせる Google のサービス
- **Gradio**: Python でブラウザ画面を作るライブラリ
- **yt-dlp**: 動画サイトから動画情報・音声を取得する無料ソフト
- **Whisper / faster-whisper**: 無料の音声認識モデルとその高速版
- **claude.ai**: ブラウザやアプリで使う Claude のサービス
- **SRT**: 秒数付きの字幕ファイル形式
